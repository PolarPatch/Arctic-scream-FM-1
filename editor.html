⚙connection

Connect the FM-1 with a USB data cable, switch it on with Arctic Scream, close other apps that use its MIDI port, then click CONNECT and allow MIDI (SysEx) when the browser asks. Chrome or Edge on a computer. TRY WITHOUT AN FM-1 runs the firmware's own code in this page instead: everything works, nothing is kept.

Sounds and sequences change live, as the knobs do. Writing to the FM-1's memory (STORE, SEND, RESTORE, samples) only happens while it is stopped and silent, and never without you clicking a button.

    ≈samples
    
        
    
        
    Any WAV (8 to 32 bit, float, mono or stereo, any rate) becomes mono, 22050 Hz, IMA ADPCM, as
          tools/fm1_sample_upload.py makes it; a slot holds 6.64 s (longer: cut, with a short fade). The root note is C4
          unless the file name has one ("drone_A2.wav"). A name is 8 characters (the slot's, what the FM-1 shows): a longer
          one keeps its number ("Sample-002": SAMP-002). Arctic Scream comes with no samples of its own: the slots are
          yours. CLEAR ALL SAMPLES empties all four.
    
      
    
      
    
    
    

    
    
      
    
        
    ▤backup
    
        
    
          
          
          
        
    
        
    A backup holds all 64 user sounds, slots A–D and the settings (the same file as
          tools/fm1_editor_test.py makes). Restoring first makes a backup of what the FM-1 has now (downloaded), then
          writes everything, then reads it back to check. Samples are not in it: the FM-1 cannot send them back yet; keep
          their WAV files.
